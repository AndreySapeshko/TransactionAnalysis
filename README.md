# Проект TransactionAnalysis
Приложение для анализа банковских транзакций

## Описание:

## Установка:
1. Клонируйте репозиторий:
```commandline
git clone https://github.com/AndreySapeshko/TransactionAnalysis.git
```
2. Установите зависимости:
```commandline
pip install -r requirements.txt
```

## Документация:
### Модуль main

### Модуль views:
1. Функция get_data_home_page

функция принимает на вход строку с датой и временем в формате
YYYY-MM-DD HH:MM:SS и возвращающую JSON-ответ со следующими данными:
Приветствие в формате
— «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи» в зависимости от текущего времени.
По каждой карте:
последние 4 цифры карты;
общая сумма расходов;
кешбэк (1 рубль на каждые 100 рублей).
Топ-5 транзакций по сумме платежа.
Курс валют.
Стоимость акций из S&P500.
2. Функция get_greeting

принимает дату в формате "YYYY-MM-DD HH:MM:SS"
и возвращает соответствующее времени суток приветств
3. Функция get_start_date

принимает дату в формате YYYY-MM-DD HH:MM:SS
и возвращает дату начала отбора операций
4. Функция get_cards_expenses

принимает дату в формате YYYY-MM-DD HH:MM:SS и возвращает
все расходы  и весь кешбек с начала месяца по каждой карте
5. Функция get_top_transactions

Выбираем из списка транзакций пять самых крупных с начала месяца 
в переданной дате, возвращаем в виде списка словарей
### Модуль utils:
1. Функция read_from_xlcx

Читает данные из xlcx формата и возвращает список словарей.
Если файл не существует или пустой вернет пустой список
2. Функция get_currency_exchange_rates

получаем курсы валют к рублю по кодам из переданнгог списка по API
с сайта ЦБР и возвращаем данные в виде списка словарей
3. Функция get_stock_prices

получаем курсы акций по тикерам из переданнгог списка по API с
Yahoo financevи возвращаем данные в виде списка словарей
4. Функция read_from_json

конвертирует json файл в python, если файла нет или пустой вернет пустой список
### Модуль services:
1. Функция analysis_categories_for_cashback

из списка операций за выбранный месяц в выбранном году подсчитываем размер кешбека
по каждой категории. Результат возвращает словарь в json формате.
 
### Модуль reports:
1. Декоратор save_report_to_file

Декоратор сохраняет резултать обернутой функции в файл с именем 
дата+имя функции в деректорию reports в корне проекта
2. Функция spending_by_category

возвращает pd Series суммы расходов по категориям за три месяца до
выбранной даты, если дата не выбрана до текоущей даты

### Логирование

Логгирование реализовано во всех модулях на уровне DEBUG. 
Логи находятся в папке logs в корне проекта. Имена соответствуют именам модулей.
